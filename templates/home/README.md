# The agent's home

A private git repository: the agent's rules, memory and skills. Not published. The rules are in [AGENTS.md](AGENTS.md).

* `experience/`: task records and their index, [experience/index.md](experience/index.md).
* `skills/`: the owner's rules on how to work and repeatable procedures. They are instructions, but check them against the current version of the tools. List each one here with a line of description.
* `notes/`: working materials such as probes, reports and raw observations. Not instructions.
* `projects/`: one file per project with what the agent knows about it: where it is, how to build and check it, its environments, the owner's rules for it.
* `archive/`: archives of discussions. Not instructions and not agreed decisions.
* `.eivoh-template`: the commit of the public core this home was last reconciled with; see "Changing yourself" in [AGENTS.md](AGENTS.md).

Directories are created when first needed.
